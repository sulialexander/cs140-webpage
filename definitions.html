Internet

The internet is the system or network that connects computers around the world to each other. They carry traffic like things like emails phone calls, or online games.

Web

The web is the system of webpages that are connected with hyperlinks that can be viewed in a browser. The web is one of the many services that exist on the internet among others like emails or video calls.

How are the Internet and Web different?

The internet is the network and the web is one of the many services that use it.

ASCII and Unicode

ASCII is a set of 128 characters that had numbers assigned to them. The only issue is that this didn't take other languages into account so, Unicode was born. Its goal was to assign a number to every character to every human language, at the moment there are 150,000 characters.

What is UTF-8

UTF-8 is a popular way to store Unicode numbers as bytes. It's useful because it ensures bytes are backwards compatible with ASCII.

URL

A URL is the full address of a resource; it indicates which server you want to reach, what to get from it, and how.

Domain Name

A domain is a readable name we use instead of memorizing ip addresses numbers, very similar to the contact name that is linked to a phone number

HTTP

HTTP is the set of rules that browsers and servers use to talk to each other. They talk by sending requests and receiving responses; anytime a page loads this process occurs.

HTTPS

This is HTTP with encryption, useful for passwords, bank details, or messages. It is commonly used to keep things safe and secure.

IP Address

It's an address for every device on the internet that indicates where the device is on the network. Computers route traffic using these addresses.

DNS

The system that translates domain names into IP addresses.

W3C Recommendations

W3C recommendations are the rules that the W3C create for how the web works. This is why one webpage can work across different browsers like Chrome, Safari, or Firefox.

XML, XHTML, HTML, HTML5

HTML, XHTML and HTML5 are languages for web pages, with HTML5 being the latest and currently used version; XML is not for web pages but a format for storing and transporting any kind of data. XHTML is a rewritten version of HTML which used XML's rules and strictness, but it eventually became unpopular.
